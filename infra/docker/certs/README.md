Certificados raíz adicionales (opcional).

Si construyes las imágenes detrás de un proxy corporativo que inspecciona HTTPS,
copia aquí su certificado raíz en formato PEM con extensión `.crt`. Los Dockerfile
lo instalan antes de descargar nada. En una red normal deja esta carpeta como está.

Los `.crt` de esta carpeta no se suben al repositorio.
